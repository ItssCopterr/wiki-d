wiki'd is an offline version of Wikipedia, made in Obsidian. This sort of thing is useful for when you don't have an internet connection and want to access data and knowledge from Wikipedia, but, as the project is a work in progress, there are only currently a few articles available. The project is shared as a .zip file containing a folder which you can import as a vault in Obsidian.
